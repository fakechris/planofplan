SUBSCRIPTION TELEMETRY

额度运行态

各 coding plan 还剩多少、何时恢复。凭据和窗口都在这页。

RECENT EDITS

文件

最近被 agent 改动的文件——哪个文件在被反复改、出自哪条对话。点击会话跳回对话页。

LOCAL SESSIONS

对话

先搜现有对话里的用户需求和 git 项目，再按项目看关系。Resume 跳回对应 CLI。用对话来搜下一步再做。

daemon 启动时会自动索引本机目录，不用定时手扫。Token 消耗请到 Token 页。

从左边选一条对话 这里读正文。有 CLI 时可以 Resume 接着做。

PROJECTS

项目

这个项目上有哪些 agent 干过什么。

从左边选一个项目 看 agent × 活动、需求流、产出 commit 和 session 时间线。

REQUIREMENTS

需求

独立于对话的需求浏览:谁在什么时候要了什么,证据落在哪些文件和 commit 上。

「用户原话」= 从用户消息直接抽取;「推断」= 会话头部退化推导,置信低一档。项目归属按需求的证据窗口(span)计算,不是整个会话。

从左边选一条需求 看原话、span 内触碰的文件和产出的 commit,可跳回源对话。

PLANS

计划

agent 写在磁盘上的计划与进展文件:身份锚文件、演进是快照序列——不做推断,只做观察。

来源:planning-with-files(task_plan/progress/findings)、PLAN.md、todo/backlog、docs/plans、HANDOFF-*.md。默认按项目分组,组内按最近活跃;谁在推进来自文件触碰归因。

从左边选一个计划文件 看快照时间线(checkbox 进度 + 所在 commit)、当前阶段和谁在推进。
